## Execution coverage cautions

- `.github/workflows/test.yml` runs Node/Python, browser, selected MySQL API tests and disposable MySQL restore. Record actual run/step outcomes and skips for the reviewed SHA.
- PHP tests may skip locally without required extensions; CI uses `KT_REQUIRE_PHP=1` for its API runs. A green local exit alone is insufficient.
- `playwright.config.js` uses Chromium, one worker and explicit `testMatch`. Root `audit.spec.js` and `test_ocm_layer.spec.js` are not included in that configured browser suite.
- `reuseExistingServer:true` risks testing another checkout. Verify the server root and chosen port.
- Inventory expansion must reconcile all reachable endpoints, background jobs, external services and user flows to these rows. This initial matrix is not a claim that every repository surface has been exhaustively examined.
