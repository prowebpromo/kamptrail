## Canonical source rows

Store pipeline-only canonical inputs under `data/sources/services/REGION.json` (`UT`, later other allowlisted states; `legacy`). Wrapper `{version:2,region,source,items}`. Source `{kind:"geofabrik"|"legacy",url,extract_timestamp:UTC|null,retrieved_at:UTC|null,sha256:64hex,license:"ODbL-1.0",categories:[...]}`. Hash actual downloaded PBF (legacy actual raw input bytes). Do not treat element edit time, extract time, retrieval time or rebuilding as inspection time. Public Geofabrik extracts only; no contributor personal metadata.

Each item: `{id:"osm:node:123",osm_type:"node"|"way"|"relation",osm_id:"123",osm_version:positiveInteger|null,edited_at:UTC|null,coordinates:[lng,lat],name:string,categories:[...],tags:{...},states:["UT"],source_region:"UT"}`. IDs include element type. One exact identity can have several categories; do not merge nearby separate objects. `source_region` binds to wrapper source; legacy `retrieved_at` may vary per-row as `retrieved_at:UTC|null`. Whitelist raw tags for evidence: amenity,tourism,sanitary_dump_station,waterway,drinking_water,fuel,fuel:lpg,shop,laundry,self_service,access,access:conditional,fee,charge,opening_hours,operator,brand,website,phone,wheelchair,shower. Bound each value to 240 UTF-8 bytes; name120; no user/uid/changeset. Geometry is representative, never guaranteed driveway/entrance.

Category names exactly `dump,water,lpg,showers,laundry,groceries,fuel`. Exact positive tags, no substring matches. Water fill requires water_point (legacy existing supported waterway tag), not drinking fountains/prose. LPG explicit LPG service; cylinder refill unknown. Showers amenity=shower, laundry shop=laundry, groceries shop=supermarket/convenience, fuel amenity=fuel. Preserve subtype/restrictions. Exclude closed/lifecycle-only features. Exclude access=no/private by default through ONE shared predicate, allow deliberate restricted view with labels; customers/permit remain visibly conditional. Never infer open now.

Use Census reference point containment for US membership; ambiguous/outside points quarantined with reason, never silently assigned. Extract polygons are buffered and cannot establish state. AK/HI/dateline fixtures required; real coverage claim requires real imported region. Exact identity dedupe across inputs chooses higher OSM version then newer extract/retrieval timestamp deterministically. A newer state extract is authoritative within its validated coverage; stale legacy removed only there, not globally. Source failure/unreviewed drastic loss keeps prior state; initial pilot never replaces national data with only UT.

Include derivation/ODbL source attribution on every basemap.

## Shared client API

New `services.js` global `KampTrailServices`, version2.14.0. Own category metadata, normalization/validation/category/access predicate, hash-validated memory+dedicated offline cache, loading and status. Cache only validated manifest/shards, not generic SW JSON shell. Max2 requests concurrently;32MiB/64shards LRU. Current manifest plus explicit saved dated fallback offline; missing offline areas are unknown, not empty.

API for consumers:
- `loadBounds(bounds,{categories,includeRestricted=false,maxShards=16,maxBytes=8*1024*1024}) -> Promise<{items,partial,offline,missing,coverage,message}>`; bounds `{south,west,north,east}` may wrap dateline.
- `loadRoute(points,miles,{categories,includeRestricted=false,maxShards=128,maxBytes=12*1024*1024})` uses conservative local segment/shard selection then exact local corridor distance. No route coordinates sent to POI providers. Explicit partial status when budgets stop work; never silent truncation/no-matches.
- `matches(item,categories,includeRestricted=false)`, `feature(item)` creates saved stop `{type:"Feature",geometry:Point,properties:{id,name,type:"service",service_categories,...}}` without treating it as campground. `describe(item,manifest)` supplies dated evidence. Expose category definitions/status/retry helpers as needed; frontend and route agents coordinate exact API.

Map/nearby/route consume this module, never independent national fetches. Category controls persist separately from campsite filters; map services zoom-gated (>=10), nearby30mile explicit radius, route categories share state. Clear/disable selections leave campsite filters intact. Long operations have progress/partial/retry; superseded viewport results cannot replace current view. Empty is explicitly none in loaded/source coverage. Historical service data may show source date offline, but no current operating-status claim.
