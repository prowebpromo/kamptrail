## Known limitations

- Visitor clearance reports are off until migration 006 is applied.
- Clearances are never tied to a route: the router returns no road ids (R11).
- Rhode Island clearances are pilot data, shown as needs checking and not compared with a rig height.
- When agency data fails, the notice uses English state names in all three languages. State total bubbles refresh on the next overview rebuild.
- CI and publish are pinned to `ubuntu-24.04`, because the repo's Playwright does not support Ubuntu 26.04.
- The English popup shows raw type values ("established", "lodging").
- Local browser runs use Chromium build 1243, so CI is the browser authority. `app.spec.js` mobile map height and a `locale.spec.js` French timeout fail on main.
