# Agent notes for KampTrail

Read the current handoff first: `docs/HANDOFF_CODEX_2026-11-01.md`. It holds the live state, the owner's standing rules, open work and the return report format.

Standing rules in brief:
- Merge only after CI passes on the exact PR head SHA. Verify every deploy live on desktop and mobile and record it before calling a release done.
- A listing is classified only from its own record or a verified exact identity. Absorbed elements' values stay attributed member evidence.
- Never rewrite a stored listing id. Every published id must keep resolving.
- Keep national clearance data out of the production package until builder, schema and client pass together.
- Owner decisions belong to the owner. Ask; do not decide.

## Delegation and model selection

Owner direction, November 4, 2026: use subagents at higher or lower capability levels as needed for maximum performance at efficient token spend.

- Delegate independent work in parallel when it reduces elapsed time or improves review quality.
- Use a smaller, faster model for bounded checks; use a stronger model/reasoning level for difficult implementation, privacy, security, identity or data review.
- Give each agent a narrow task and explicit file ownership. Keep shared browser sessions and conflicting edits with one owner.
- The lead integrates findings, verifies the combined result and records unresolved gates. Delegation does not expand publication or production authorization.
- Stop or retire agents when their assigned work is complete. Avoid redundant broad reviews and idle delegation.
